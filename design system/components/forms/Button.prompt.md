One-line: Glow Within's rounded, gentle action button — use for any tappable action, from full-width primary CTAs to inline amber "ghost" text links.

```jsx
<Button variant="primary" size="lg" full>Water with gratitude</Button>
<Button variant="secondary">Paste image link</Button>
<Button variant="ghost" iconRight={<Icon name="arrow-up-right" size={16} />}>Set them</Button>
```

Variants: `primary` (deep sage, main CTA), `sage` (soft sage), `secondary` (white with hairline border), `ghost` (amber text link, often with a trailing arrow). Sizes: `sm` `md` `lg`. `full` stretches to 100%. Weight is 600 except ghost (500).
