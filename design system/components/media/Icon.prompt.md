One-line: Inline line icon in the app's Lucide-based icon language (2px stroke, round caps, currentColor) — use anywhere a glyph is needed.

```jsx
<Icon name="sprout" size={20} />
<Icon name="arrow-up-right" size={16} color="var(--gw-amber)" />
```

Available: sun, sprout, target, image, chevron-left/right/down, arrow-up-right, plus, x, check, droplet, heart, sparkles, flower. Inherits text color via `currentColor` unless `color` is set.
