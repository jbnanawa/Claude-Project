# Glow Within

A soft, feminine minimal React app for goals, daily affirmations, and a personal vision board. Entries persist in local storage.

## Features

- **Dashboard** — overview of active goals, completed goals, and recent vision pieces
- **Goals** — add goals by category (Wellness, Career, Relationships, Mindset, Abundance, Creativity)
- **Daily affirmation** — a rotating affirmation for the day
- **Vision board** — gallery of images with manifestation descriptions (URL or upload)
- **Local storage** — goals and visions persist across sessions

## Stack

- React + TypeScript (Vite)
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
